# Customer decisions

These four questions are unanswered. The current demo behavior is recorded here so it can be reviewed. It is not a decision.

## 1. Should Management remain a separate role?

Unresolved.

Today Management is a separate read-only role. It can open reports, the roadmap, and operational records. It cannot approve orders, post stock, edit shipments, or use chat.

## 2. Can Workers also perform data entry?

Unresolved.

Today a Worker can upload loading and unloading photos and operate the assigned warehouse. A Worker cannot edit shipment identity, CMR details, customs fields, or customs confirmation.

## 3. Who records customs confirmation: Customer, Owner, or Data Entry?

Unresolved.

Today Owner and Data Entry can record a confirmation with a name, date, and proof file. That form is provisional. It does not confirm the seller and it does not block dispatch. A Customer can still confirm the seller separately when the company matches the shipment.

## 4. Which customs fields must appear on CMRs and reports?

Unresolved.

Today the outbound customs fields and the CMR details are separate demo records. No confirmed list says which customs details must be copied onto a CMR or into a report.
